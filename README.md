# WANTED: ATOM

원자모형의 변천사를 탐정 추리극 형식으로 따라가는 픽셀 비주얼노벨 애니메이션이다.
돌턴, 톰슨, 러더퍼드, 보어, 슈뢰딩거의 증거를 하나씩 살피며, 탐정이 원자의 몽타주를 고쳐 그려 나간다.

**바로 보기:** https://skadmstjr.github.io/tofindatom/

## 조작
- 클릭 · 스페이스: 다음 대사
- A: 자동 재생 켜기/끄기
- H: 대사창 숨기기
- M: 효과음 켜기/끄기
- 오른쪽 위 메뉴: 속도, 장면 이동, 전체 화면

## 구성
`index.html` 파일 하나로 동작한다. 배경과 증거 애니메이션은 캔버스로 그리고, 효과음은 Web Audio로 합성한다.
글꼴은 [갈무리(Galmuri)](https://github.com/quiple/galmuri) (SIL Open Font License 1.1)를 필요한 글자만 추려 내장했다.
